## 格式适用性

四类课程共用对象初态、逻辑位置、步骤、动作和详情，组件只决定渲染方式。拓扑节点与报文转换为 Vue Flow 节点，边转换为 Flow 边；公式根据 status 选择 states 中的 TeX；几何将局部点集映射到 size；图片按 assetId 解析并显示 label 标注。Schema v1 无结构变化，仅在播放语义文档明确几何和图片适配细则；数学样例调整 size，生产图片调整 position/size。

五种动作均从契约进入纯求值器，隐藏不停止移动。静态 details 与当前 status/位置/可见/高亮由同一重建结果派生，不另设详情计时器。未知组件版本与动作不能静默播放。专属动作需先扩 Schema/校验，再实现组件纯处理器，当前扩展入口只是工程边界，不宣称任何专属动作已交付。

## 状态重建可行性

每次从初态复制，动作按绝对开始时间、步骤索引、动作索引排序。每个 move 捕获开始时之前获胜移动的插值位置；后移动保持覆盖优先，即使结束也不恢复旧移动。瞬时动作按属性叠加，同刻后者覆盖。内部边界按前步末尾、新步 0ms 顺序执行，结束时间归末步。逻辑时间取整数毫秒，非法非有限时间拒绝、超范围夹紧。

固定预期验证 x=50/125/200 的重叠移动；额外用例验证瞬移覆盖、同刻状态、前步末尾与新步边界、隐藏移动、高亮撤销。四课 49 个时间点各自顺序与逆序重建相同，修改返回状态不污染下一次计算。时钟测试验证暂停、恢复、隐藏页面基准重置、末尾停止及重播；浏览器实际控制与同时间 DOM/详情复验支持机制可行。当前逐帧从初态重建适合少量对象的原型；大场景性能、索引/快照优化与广泛随机压力验证尚未执行。

## 组件限制与 S03 交接

- 当前共享组件加载首章首场景，换课程暂停并进入 0ms；章节/多场景导航留 S03。没有倍速、完整报文表、业务保存、发布或完整编辑器。
- Flow 使用只读节点与连线，拖动/连线/缩放编辑未实现；平台坐标与 Vue Flow 内部数据隔离，S04 写回仍需独立适配。公式与几何覆盖当前样例，不含符号推导、参数仿真、任意几何工具或自主分支。
- 图片解析由外部资源提供方注入，当前仅本地自制示意素材，不是资源上传/权限/版本保留能力。共享组件 API 可由后续后台预览及学员页面复用，这两类正式业务页面尚未交付。
- 小屏内部滚动保留可读逻辑尺寸，桌面自适应缩放；整体学生端移动体验、Safari/Android/iOS 真机待 S07/S08。
- 扩展动作处理器须保持纯函数；当前无已发布自定义动作，也未验证扩展动作与持续 move 对同一位置竞争的语义，不应在未补充契约时开放该组合。
