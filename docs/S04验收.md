## 保护与边界

- Flow 内部 position/selection/handles/viewport 等不整体序列化；拖拽只写 position.x/y，连线创建平台 edge 对象，缩放仅改变查看视口。契约和播放语义不变。
- 对象删除前检查动作、连线和 TCP 源/目标引用，明确列出引用并阻止，不静默删除动作。仍被报文引用的网络设备不能清除外观/地址。课程资源被图片引用时不能解除引用。
- 章节/场景整体删除需确认包含的对象与教学步骤；至少保留一个章节/场景/对象。新增场景生成文字对象、无动作初始展示步骤，并登记组件。这不代表 S05 编排已交付。
- JSON 仍可通过高级折叠面板审查和手工合并，但本轮四类基础配置完全使用表单和画布。没有本地自动草稿恢复；未保存时须保存或下载，关闭提醒不能替代持久化。
- 资源沿用 PNG/JPEG/WebP/PDF 与现有权限，SVG 未净化继续拒绝。没有公开草稿、发布资源或修改账户归属。
- 本机 admin 沿用忽略目录凭据；没有输出或提交口令。没有停止无关服务/容器或重新初始化数据库，保留全部已有未提交改动。
- Docker/Compose 新容器问题、正式素材/作者内容批准、真机与大规模性能仍留既定后续阶段。下一阶段 S05 尚未启动。
