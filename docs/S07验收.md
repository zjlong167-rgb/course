## 已知边界与下一步

本地记录单浏览器保存，不同步设备或账号，不记录观看时长/成绩；退出尽力写入，浏览器崩溃可能损失最近 500ms。版本迁移严格比较当前完整场景；任何内容/ID 差异都保守失效，回滚不查历史学习记录。公开页通过刷新按钮读取最新指针，不自动在播放中替换课程；旧版本资源失效会提示后可刷新。

完全禁用浏览器 Storage 时，开发构建的 Vue devtools 在学员代码前报错；最终产品生产构建已实测可正常启动与降级。开发模式仅对学习记录命名空间注入失败，生产模式对全部 Storage 方法注入失败。该开发工具限制未计作生产能力。

正式作者内容/素材批准、作者自主操作试用、真机及更多浏览器检查留 S08；Docker/Compose 与正式部署、备份恢复留 S09。无外部生产发布。
