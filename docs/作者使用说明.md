# 作者使用说明

打开 /#/studio 登录。建课起点可选空白和四模板；生产模板须先上传PNG/JPEG/WebP图片。PDF是附件；SVG暂拒绝。每个课程实例独立生成ID。

编辑课程信息、章节场景、对象和连线；画布拖动调整布局。被动作或连线引用的对象须先解除引用才能删除。步骤时长以毫秒计，只有移动动作有持续时间；同一时间修改同一属性时靠后动作优先。移动结束不能超过步骤时长。缩短失败按提示先改动作。

保存后刷新重开复核。发生409冲突时本地内容保留，先下载副本、比较服务器正文，再手工合并并明确采用新修订。失败时不要反复覆盖。尚无本地自动恢复，离开前保存。

本地预览读取未保存快照；授权预览读取已保存草稿。两者共用学员播放器。错误提示可点定位修复。管理员保存后发布，发布失败或结果未知使用界面原键重试；勿在等待时反复创建新请求。历史版本需要授权预览，回滚须填写理由，不改变当前草稿。

学员 /#/catalog 匿名查看已发布课程。播放、暂停、倍速、单步、回退、跳转和重置使用同一时钟；切场景暂停起点。手机画布可横向滚动。学习记录只保存在当前浏览器，表示最近访问位置和主动复习标记，不表示成绩或观看时长；课程内容变化可能重置记录。

正式四课内容需按《作者试用与内容确认》审阅；开发候选和自动化验收课不视为正式批准课程。
