## 实现与边界

motion.ts 只负责表现几何：平台的一条边生成双向通道，网络位置由现有状态加方向偏移，时序进度由课程 move 时间映射。NetworkCanvas 的六条通道、移动标记、箭头长度和游标都取 SharedPlayer 传入的 time/states；没有新计时器、任意脚本、Vue Flow 数据入侵或课程 ID 分支。操作暂停、任意 seek 和重播后，两视图仍是同一目标时间的投影。

此次落实网络双向箭头与时序渐进传输的具体行为；并不声称参考站全部页面、课程数量、素材或像素完全相同。课程作者确认、真机兼容、复杂混合场景、重复发送事件模型与 S03 后端仍待后续；本轮不改变它们的状态。
