# 公式原型与素材（S01-07）

选择 KaTeX，确切版本在 frontend/package.json 和 package-lock.json。当前需求只有作者编排的静态公式与分步切换，KaTeX 的 renderToString 可直接配合 Vue；SVG 负责几何图形，两者共享容器布局。后续接入统一课程播放器，S01 独立实验室不作为四类场景播放器实现。

原型覆盖面积分解、展开、消项和 3/4/5 验证；公式输出 htmlAndMathml，trust=false、strict=error、throwOnError=true、maxExpand=1000。不能把作者公式当作任意 HTML。无外部字体/CDN 请求，字体打包到构建产物。依据：[KaTeX 选项](https://katex.org/docs/options)、[安全说明](https://katex.org/docs/security)。首版需要的分式、上标、乘号均已用于原型；不需要完整 LaTeX 环境。复杂宏/不支持命令在录入时应报错，由作者拆分或修订。

实际浏览器结果与截图见 `docs/evidence/prototype-results.json` 和 `formula-*.png`。脚本验证 1440/390/320 宽、四步公式、MathML、重置、页面横向溢出和运行时错误。长公式允许公式框局部横向滚动，不能挤宽整个页面。像素截图仅表示 Chromium 桌面与手机尺寸模拟，不代表真机 Safari 测试。
