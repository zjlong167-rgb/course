# 播放语义 v1（S01-04）

所有时间为非负整数毫秒；画布为逻辑坐标，屏幕缩放不改变课程数据。数组顺序就是章节、场景、步骤及同时间动作顺序，不保存 Vue Flow 的 handles、viewport 或选中状态。ID 在单份课程的课程/章节/场景/对象/步骤/动作间全局唯一，资源 ID 单独命名空间。一个场景中的动作只能引用该场景对象。

场景时间为各步骤 durationMs 之和。步骤占用 [开始,结束)，最后一步结束属于最后一步；恰好到内部边界时先应用前一步结尾动作，再应用新步骤 atMs=0 动作。讲解和步骤选择取目标时间所属步骤。跨场景进入目标场景的 0ms，不继承前场景状态。章节仅组织导航。

播放时 requestAnimationFrame 提供墙钟增量，乘倍速累加逻辑时间；暂停冻结逻辑时间，恢复重新设墙钟基准，隐藏标签恢复不追赶时间。到场景末尾暂停，不自动跨场景。S01 仅确定规范，调度器在 S03 实现。

## 确定性求值

1. 每次 seek / back / reset 从对象 initial 和 position 复制状态，绝不复用先前求值的可变对象。
2. 将动作转换成场景绝对开始时间，按 `(绝对开始时间, 步骤数组索引, 动作数组索引)` 稳定排序。同属性由后开始的动作覆盖；同开始时间以数组靠后者为准。
3. 按开始顺序处理全部开始时间 ≤ t 的动作。show/hide 设置 visible，highlight 设置布尔值，setState 设置 status；它们 durationMs 必须为 0，不隐式撤销。move 是线性插值，持续 0 则瞬移。move 起点为它开始时刻由所有更早排序动作求出的 position；结束后保留终点。后开始的 move 即使结束也不恢复被覆盖的旧 move。
4. 不同属性独立叠加。隐藏仅影响显示，不停止移动和状态计算；高亮也不自动取消。资源、对象详情为静态内容，动态详情读取目标时间 status，不维护另一个报文表计时器。
5. 重置暂停并 seek(0)，所以会应用 0ms 动作，不是单纯显示 initial。单步为暂停并跳到下一步骤开始；已经最后一步时跳场景末尾。回退跳当前步骤开始，若已在开始则跳前一步开始。任意跳转都暂停。选中对象保留 ID（目标场景存在时），否则清空；详情只从重建状态派生。

## 可验证输入与期望（供 S02/S03 实现，不声称已实现播放器）

初始对象 p: x=0,y=0,visible=true,highlight=false,status=idle；第一步 1000ms，第二步 1000ms。

| 动作 | 时间与参数 |
| --- | --- |
| 第一步 a1 move | 0ms, 1000ms, x=100,y=0 |
| 第一步 a2 move | 500ms, 500ms, x=200,y=0 |
| 第一步 a3 hide | 750ms,0ms |
| 第二步 a4 show | 0ms,0ms |
| 第二步 a5 setState | 0ms,0ms,status=done |

| seek 场景时间 | 期望 x / visible / status / 当前步骤 |
| --- | --- |
| 0 | 0 / true / idle / 第一步 |
| 500 | 50 / true / idle / 第一步（a2 起点固定 50） |
| 750 | 125 / false / idle / 第一步 |
| 1000 | 200 / true / done / 第二步 |
| 2000 | 200 / true / done / 第二步，暂停 |

顺序求值 0→750→1000 与倒序 1000→0→750 的 750ms 结果必须相同。两个同时间 setState 取数组后者；hide 与 move 同时发生都生效。seek 超范围夹紧到 [0,2000]；NaN/非有限时间拒绝。以上输入另存 `contracts/playback-cases.json`，S01 只检查用例数据，不把未运行的重建测试记为通过。

## 格式与扩展

Schema 使用 JSON Schema 2020-12；formatVersion 首版只接收 1.0.0，升级由显式迁移器完成。组件版本为精确 1.x.y，运行时必须在注册表找到对应版本（S01 样例使用 1.0.0），不能用“同大版本”跳过兼容检查。Schema 检查形状，语义层检查 ID、引用、动作越界和组件匹配；发布阶段另查数据库资源、文件及注册表。专属动作后续增加 schema 分支及组件求值器，不允许任意脚本执行。Schema [规范来源](https://json-schema.org/draft/2020-12)。

公式组件 v1.0.0 的内容约定：content.tex 为默认公式；content.states 是 status 到 TeX 的可选映射，存在当前 status 对应项时显示该项，否则显示默认 tex。setState 只改变 status，适配器纯函数选择公式，不执行脚本。数学样例第二步显示面积等式，第三步 simplified 显示定理。此为契约，组件适配器将在 S02 实现。

## S02 组件适配细则（2026-11-12）

- 几何 points 为对象局部坐标；适配器将点集包围盒映射到 size，position 为其画布位置。数学样例 size 调整为 240×180，保持原三角形比例；公式容器扩为 530×110。修改布局不影响逻辑时间。
- 图片从 content.assetId 经外部注入的资源解析函数加载，content.label 为图下注释，details 为可点击详情。生产样例图片移动到 y=350，避免遮挡物料路径。当前自制 SVG 是技术素材。
- 注册表精确匹配 type@version 与对象类型；未知版本或动作报错。专属动作扩展键为 component:action，由纯状态处理器执行；新动作进入课程文件前必须先扩充 Schema 与校验，不允许在页面执行课程脚本。S02 未新增专属动作契约。
- 原型每份样例加载首章首场景，换课程重新挂载播放器并暂停于 0ms。跨场景导航、倍速、完整报文表与异常反馈按 S03 推进；不因本阶段已有时钟而标记 S03 完成。

## 参考站体验优化：网络内容与组件版本（2026-11-12）

课程 formatVersion 继续为 1.0.0，Schema 增加可选 content.visual（laptop/server/router/cloud）、address 和 packet；新能力需精确注册 flow@1.1.0，旧 flow@1.0.0 与其他组件继续支持。visual 仅用于 node；packet 仅用于 packet 对象，包含 TCP、源/目的对象 ID、两端端口、flags、seq、可选 ack、帧字节数，端点必须存在并具有设备造型与地址，ACK 标志要求 ack 值。旧播放器不应将 1.1.0 内容按 1.0.0 静默播放。

设备 position/size 仍为逻辑包围盒，连线路径使用包围盒中心。报文路径由多个连续 move 编排，未增加可执行脚本或新动作类型。当前 TCP 为 3×6000ms 的教学时间，非真实网络时延；每个报文对象表示一次传输，表格的发送时刻取首次 show，抵达时刻取该对象最后一个 move 的结束。隐藏后报文表与详情仍保留抵达结果，跳转后从同一时间派生；一个对象重复发送需在后续事件模型扩展后支持，当前作者应为每次传输创建独立对象。

TCP 样例 SYN 到达时服务端进入 SYN-RECEIVED，SYN+ACK 到达时客户端进入 ESTABLISHED，最后 ACK 到达时服务端进入 ESTABLISHED。SEQ=100/300 与 ACK=101/301 是教学值；帧大小 60 B 为简化示意，非固定 TCP 首部长度。

倍速支持 0.5/1/1.5/2，切换时丢弃旧墙钟基准，暂停仍冻结逻辑时间。网络/时序视图切换不修改逻辑时间；点击步骤、报文表或时序箭头暂停并跳到对应发送时刻，更新所选报文；普通时间跳转保留手动选择，无手动选择时跟随当前步骤。选择设备显示设备说明与状态，选择报文显示结构化字段。空格播放/暂停、左右键步骤前后、Home 重置，表单和按钮获得焦点时保留其自身键盘行为。

## 双向网络/渐进时序表现（MA，2026-11-12）

一条平台 edge 在网络视图投影为两条反向平行通道，方向箭头放在设备边界外；这不创建额外的课程对象。报文仍按原 move 重建逻辑坐标，表现层按当前动作方向添加 10 逻辑像素法向偏移，落在对应通道。当前 move 段决定活跃通道，去回程分色；不借助 CSS 自行计时。偏移不写回课程或状态。

时序视图每个报文由发送端生命线开始斜向下延伸至接收端，进度按首个 move 开始到最后 move 结束映射到 [0,1]；发送前保留可点击的步骤等待区，不预画完整箭头。发送后起点/移动标记、到达圆环、方向和当前教学时刻均取同一逻辑时间；已到达记录保留，悬停/点击与右侧详情及报文表联动，视图切换不重置时间。画布报文 hide 不删除时序历史。多段网络跳转在时序中压缩为端到端传输，不表示中间路由节点参与 TCP。

## S03 已实现导航与生命周期（2026-11-12）

SharedPlayer 负责课程/章节/场景导航，ScenePlayer 持有单场景唯一时钟和 RAF。多场景按章节数组顺序展示导航；切换到任意场景时销毁旧场景播放器，进入目标 0ms、暂停、清空选择/详情、恢复 1×。切换课程或替换课程正文也重新建立场景状态。单场景的已有页面外观保持原样。场景结束暂停，不自动跨场景；同场景 seek/back/reset 保留选择 ID 并从目标重建状态读取详情。四类课程均有 0.5/1/1.5/2×；键盘统一响应（输入控件内不截获）。后台预览读取授权已保存草稿，复用同一 SharedPlayer，没有第二套求值逻辑。


## S07 学习位置与版本迁移（2026-11-13）

- SharedPlayer 新增可选 initialPosition 与 position 事件；ScenePlayer 用现有 LogicalClock.seek 恢复毫秒位置，同一 RAF/重建函数派生图形、讲解、公式与详情。后台仍用相同组件，未另建学员时钟或动作。恢复暂停于指定位置、1×，不恢复对象选择、详情或网络/时序视图；场景/课程切换销毁旧实例。导航切回曾访问场景也从 0ms 暂停，只有重开课程恢复最近一次访问位置。
- 自动记录的是“访问位置”，包括手动跳转的位置。播放、跳转、单步到末尾均不自动标记完成；“已复习”仅由学员主动标记/取消场景，不证明实际观看时长或掌握程度。
- 同版本：场景 ID 存在、完整场景 JSON 签名一致、时间为有效范围内整数时恢复；主动复习标记过滤为现有场景 ID。签名包含对象、步骤、动作、时长、初始状态、布局、讲解及资源别名，任何差异均保守失效。
- 再发布/回滚同规则：仅当前场景 ID 与完整签名完全一致才保留其毫秒位置，全部复习标记清空。课程标题/简介或章节调整而场景不变可保留位置；场景、对象或步骤 ID、动作、时长等改变时重置为首场景 0ms 并说明原因，不按数组位置猜测迁移。仅保存一个最近版本记录，回滚不承诺找回该历史版本过去的记录；与当前记录签名不符仍失效。签名比较同样应用于同版本损坏记录。
- 损坏 JSON、错误 schema、负数/越界/非整数时间、非法字段被忽略；存储不可用时继续内存播放并显示不能保存/清除的原因。清除成功删除该 slug 的记录、复习标记并暂停于起点，不立即重写空位置；后续学习操作会产生新记录。页面隐藏时原时钟仍按 S03 规则停止追赶，退出时尽力刷新待写位置，不保证浏览器进程崩溃前最后 500ms 已落盘。
