## 作者任务与验证

- **S05-01/02**：StepEditor 在场景内编辑步骤标题、讲解、时长及动作的目标、类型、起止参数，支持增删与上下移。动作随步骤移位；同刻动作按数组顺序求值。删除及带参数动作换型需确认，越界时不截断已有内容。空白课用表单将新步骤上移、将移动动作上移、尝试非法时长和开始时间并检查原值，随后删除移动动作。
- **S05-03**：本地预览取当前正文的独立快照，不改 revision；授权预览从服务器取保存修订，两者复用 SharedPlayer。每门课在保存之前对比两处讲解；保存重开后逐步核对当前时间、讲解及详情，再以 2× 连续播放至末尾并检查暂停。播放器截图 [TCP](evidence/s05-player-1.png)、[审批](evidence/s05-player-2.png)、[数学](evidence/s05-player-3.png)、[生产](evidence/s05-player-4.png)。
- **S05-04**：instantiate 从空白或分镜创建实例。纯测试为四种模板各生成两份，断言原模板和两个实例的所有实体 ID 均不相交；按原对象逐项核对连线、TCP 源/目的和动作目标；改一份不影响另外两份。开发资源别名不入库；生产课使用登录会话上传的 [工位 PNG](../samples/assets/station.png)，持久化目录与资源权限沿用现有策略。
- **S05-05**：前端和 Go 以 JSON Pointer 标出结构及语义错误，工作台将其映射到章节、场景、对象或步骤/动作控件。通过表单填入非法移动终点，服务器校验提示并定位到 x 输入框；另模拟一次含无效动作目标的草稿读取（不向数据库写入坏数据），在页面分别执行本地保存校验和真实服务器校验，定位目标选择框并修正保存。Go 新版的 HTTP 集成还直接断言了两个 422 响应的完整路径。
- **S05-06**：真实 Chrome 从四模板创建实例，改章节、场景、对象标签及坐标，去掉所有原步骤，按分镜用表单重新创建步骤及 51 个动作。测试只读正文做断言，未用 JSON 写入课程。逐动作比对目标、类型、参数、起始与持续时间；通过实际 API 保存到 MySQL，重开后全文深比较，再逐课播放。此为自动化作者操作验证，正式作者试用与内容批准留给 S08。
